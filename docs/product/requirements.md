# Product requirements

MVP includes accounts, courses, pasted notes, Gemma question generation, a review/approval gate, practice mode, timed exam mode, deterministic scoring, explanations, and basic progress. Initial question types: single choice, multiple select, true/false. Generated content is untrusted and must be reviewed.

Not included yet: file/PDF ingestion, async workers, spaced repetition, multi-user sharing, short-answer grading, email verification/reset, and production security hardening.

Acceptance path: register → create course → paste notes → generate draft → review/approve → practice or exam → submit → review answers and score.
